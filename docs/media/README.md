# Product captures

These images and the short animation are captures of the running MOCsmith interface. The model is the bundled Chick sample from Kenney Cube Pets (CC0 1.0). The Labrador mosaic input is Dktue’s CC0 photograph. Full sample credits are in [credits](../credits.md).

`editor.webp` shows the source model beside its converted parts. `build.gif` records actual step navigation. `mosaic.webp` shows the photo-to-mosaic workflow. Original MOCsmith interface artwork follows the project documentation licence; third-party sample assets retain their own licences.
