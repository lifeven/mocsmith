# MOCsmith 0.1.0

Released 2026-10-15 at https://mocsmith.lifeven.com/.

This release includes model conversion, part editing, automatic assembly plans, PDF/LDraw/CSV exports, photo mosaics, set-inventory fitting and optional local depth inference. The interface supports English and Chinese.

## Source and deployment

- Application source: the initial release in the [public repository](https://github.com/lifeven/mocsmith).
- Cloudflare version: `c7409b69-26e4-48e5-86e3-8ef251092ece`.
- The initial release is built from the clean public repository and deployed with Wrangler. Source availability is verified independently from hosting.

## Verification

300 Node tests and 24 Chromium browser tests pass. [GitHub CI](https://github.com/lifeven/mocsmith/actions/workflows/check.yml) passes for the application source.

The browser matrix covers desktop, tablet upright and sideways, phone upright and short landscape, and a narrow phone, in English and Chinese. It checks access to primary controls, drawer/build transitions, canvas space and horizontal overflow. Product smoke checks include part selection, set search, step navigation and PDF/LDraw/CSV downloads. Optional relief completes on the Labrador sample and produces 574 support plates with the selected settings, using GET model downloads from Hugging Face.

The deployed 44 HTML route entries, 17 JavaScript/CSS resources and sharing image match the local artifact. Unknown paths and internal-file probes return 404. Frame protection, MIME protection, referrer policy and permissions policy are verified. The live app converts the Chick sample and exports its 63-page PDF book.

These checks use Chromium and emulated viewports. Physical-device Safari/Android and physical brick-build strength are not certified by this release.
