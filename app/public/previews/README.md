# Display previews

`models/` contains brick-model WebP thumbnails. `mosaics/` contains mosaic previews and small photo insets. These are derived display assets, separate from the converter inputs in `../samples/`.

Generate them with `tools/thumbs.sh` and `tools/mosaic-thumbs.sh` from the app directory. They retain the input assets’ licences and credits; see `../../../docs/credits.md`.
